# Credit policy for this repo (applies to every skill)

1. **Forked / vendored third-party skills keep FULL original credit.** The fork stays as
   close to verbatim as practical; a `CREDITS.md` in the skill folder and an entry in the
   repo README name the original project, its authors and their URL. Nothing about the
   original text that constitutes the credit is ever trimmed.
2. **Borrowed ideas get cited.** Any method, script or reference page adapted from another
   maintainer cites the source (URL, commit SHA) where the borrow is non-trivial.
3. **Personal names stay out.** Commit trailer examples use placeholders; the user's real
   identity is their `git config`. Real device data (fork maps, sync logs) is gitignored
   under `_personal/`.
4. **No AI attribution trailers** in commits anywhere — human co-authors only.
5. **Our own skills are the author's work.** If someone forks this repo, per (1) they keep
   our credit in the same way.
